# rawr brand

The approved rawr icon, wordmark and README banner, in a dark mode (on Rex's Twilight tile) and a light mode (on Rex's Default light tile).
The mark is a small dinosaur asleep in a glass terminal window, waking: an agent coming back to its pane.
It belongs to Rex's visual family without reusing Rex's own mascot, icon or wordmark.

These are raster masters.
Vector versions will replace them, drawn once from the dark mode's outlines, with the light mode as a recolouring of the same paths.

## Files

| File | What it is |
| --- | --- |
| `rawr-icon-dark.png` | app icon, Twilight tile, 864 px square, transparent outside the tile |
| `rawr-icon-light.png` | app icon, Default light tile, 864 px square, transparent outside the tile |
| `rawr-banner-dark.png` | README banner, night scene, 1774 x 443 (4:1) |
| `rawr-banner-light.png` | README banner, dawn scene, 1774 x 443 (4:1) |
| `rawr-wordmark-reference.png` | the approved "rawr" letterforms, the reference every lockup and banner copies |

The icons carry no page colour: place them on any background as they are, with no outline, glow or shadow added.

## Type

The wordmark is drawn, not set in a font.
In the banner, "wake and resume" and "REX AGENTS" are rebuilt as vector type from Fredoka SemiBold and Quicksand Bold, both under the SIL Open Font License 1.1.
